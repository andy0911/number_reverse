# 感想戦（対局後の盤面確認）デザイン案

## 課題
対局が `.finished` になると、盤面の上に全画面スクリムの `DialogCard` が被さり、「タイトルへ」しか押せない。
勝敗の決まった最終盤面（どこが取られたか・色の分布）を見返す手段がなく、感想戦ができない。

## 方針
- 結果ダイアログに「盤面を見る」を追加。押すとダイアログとスクリムを外し、**最終盤面をそのまま操作不可で見られる**状態（感想戦モード）にする
- 感想戦モードでは、盤面下の手駒ピッカーの位置に「結果バー」を置く。そこから結果ダイアログへ戻る／タイトルへ戻れる
- Core（ルール）は変更しない。`App` 層の表示状態のみ（`GameView` の `@State`）
- 手順の巻き戻し（一手ずつ再生）は今回の範囲外。要望が出たら次段で `GameState` の履歴を持たせる

## 画面

### A. 結果ダイアログ（変更）
```
┌──────────────────────┐
│     先行の勝ち！      │  title2.bold
│  先行 12 − 9 後攻     │  subheadline
│ [盤面を見る] [タイトルへ] │  GlassEffectContainer, 横並び
└──────────────────────┘
```
- 「盤面を見る」: `.glass`（副）／「タイトルへ」: `.glassProminent`（主。広告カウント対象はここだけという既存仕様を維持）
- 順序は 副 → 主 の左右（親指で届く右側に主）

### B. 感想戦モード
```
[‹ タイトルへ]                  （既存の上部バー）
┌ 後攻  手駒0   9マス ┐        ← 勝者側は色枠を強調
 先行の勝ち！  12 − 9           ← statusText（「ゲーム終了」を結果文に置換）
┌── 8×8 盤面（最終局面） ──┐    ← タップ不可。最後の置き・裏返しのハイライトは残す
└──────────────────────┘
┌ 結果バー（手駒ピッカーの位置）┐
│ 感想戦中   [結果を表示]    │
└──────────────────────┘
┌ 先行  手駒0   12マス ┐
 バナー
```
- 結果バー: ガラス背景（既存 chrome と同じ質感）、高さは手駒ピッカーと同程度（盤の縦幅を変えない）。結果文は statusText に一本化し、バーには「結果を表示」（副）と「タイトルへ」（主）だけを置く
- 「結果を表示」: ダイアログに戻る（A）
- 終了後は PlayerBar の勝者側に「勝ち」バッジを出す（色枠だけに頼らない）
- 上部「タイトルへ」: 対局が終了済みの場合は結果ダイアログの「タイトルへ」と同じ処理（広告カウント対象）にする

## 状態遷移
```
finished ──(盤面を見る)──▶ reviewing ──(結果を表示)──▶ finished(dialog)
   └──────(タイトルへ)────────┴────────(タイトルへ)──▶ exit（広告ポリシー適用）
```

## アクセシビリティ・文言
- ボタンは 44pt 以上、VoiceOver ラベルは表示文言と同じ（「盤面を見る」「結果を表示」）
- 結果バーは「感想戦中。盤面を確認できます」を読み上げ
- 勝者の識別は色枠だけに頼らず statusText の文言でも示す

## デザインレビュー（design-critique）反映
- 結果文の重複を避け statusText に一本化／下部に主ボタン「タイトルへ」／勝者バッジ／上部ボタンも広告ポリシー経由、を反映済み
- 一手ずつの再生は次段（🟢）

## 独立レビュー（subagent）反映
- ボタンの 44pt/全幅（ラベル内側の frame + controlSize(.large)）、勝ちバッジの文字色（色は縁と薄い地）、終了後の勝者の色枠、結果文を「先行 N − M 後攻」形式に、`isModal`、成功ハプティクスを終了時の 1 回だけに、を反映済み
- 未対応（次段）: Dynamic Type の縦並び切替、盤面セルの VoiceOver ラベル、「感想戦」文言の見直し

## 受入条件
1. 終了ダイアログから盤面を隠さずに最終盤面を確認できる
2. 感想戦中に盤面タップで駒が置かれない
3. 感想戦から結果ダイアログへ戻れる
4. 「タイトルへ」はダイアログ・上部バーどちらからでも広告ポリシーが 1 回だけ適用される
5. 小画面（compact）でも結果バーで盤面が縮まない
