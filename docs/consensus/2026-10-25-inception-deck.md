## 1. 論点

- 決めること: プロダクト目標「トオカエシ単体の広告収入で毎月5,000円を安定して稼ぐ」を達成するための、インセプションデッキ10項目の中身。
- 固定条件: 予算は月1万円まで(トオカエシ個別)。撤退ラインは3ヶ月(撤退=投資停止、アプリは消さない)。お金がかかる操作・広告変更・審査提出・メタデータ反映は承認後。原案者クレジットは「原案: @bdgame_」。
- 実測(App Store Connect Sales API / AdMob、2026-10-25取得): 直近30日(9/25〜10/24)の新規DL 3件、AdMob収益約25円、表示164回、eCPM約152円(AdMob単独値)。Apple Ads(トオカエシ)は未出稿。他アプリ(カラダナビ等)のCPI実績は376〜801円。
- 算術: 月5,000円=日約167円。日167円÷152円×1,000≒日約1,100表示。現状は日約5.5表示(164÷30)。M・PMとも「約200倍の不足」と記載。
- 推測(根拠弱い): 広告LTV 6〜24円/人(M)。
- 状態: docs/inception-deck.md は未作成。

## 2. 各役割の最終意見(第1ラウンド+第2ラウンド回答)

### マーケティング専任者(M)
- 結論: 3ヶ月の主軸は「測れる状態→無料流入→戻る理由の確認」。Apple Adsは検証の少額実験。達成確率は低い(信頼度 中〜低)。
- 必要DAU: 1人日5〜10表示でDAU110〜220を基準に修正。20表示(DAU55)は根拠がないとして取り下げ。「20〜35人」案の撤回を明記。実測(表示数÷DAU)で4週後に置換。
- しきい値: DAU30案を取り下げ、PM案に寄せる。継続=30日平均DAU100以上かつ日次広告収益70円以上かつD7 10%以上で増加。保留=DAU40〜100またはD7 5〜10%。撤退=DAU40未満または日30円(月約1,000円)未満またはD7 5%未満。30日平均=直近連続30暦日の単純平均、DAUは起動日ごとのユニーク端末数、欠損は分母から除外、欠損10日超は判定せず保留。代理指標=AdMob日次表示÷5をDAU相当(推測)。実測後の再確認を条件に受ける。
- 固定軸: 予算上限(月1万円、総額3万円)と3ヶ月の撤退ライン。可変=範囲・施策順・実支出。下限=計測整備とコンプラ整合。保留は1ヶ月・無料施策のみ・再延長しない。
- 凍結: 賛成。期間=1ヶ月目の計測完了〜3ヶ月目の月末判断まで。解除=(a)4週分の計測で1人日表示数が実測できている (b)継続/保留/撤退の判定が出ている。例外=体験を壊す不具合修正のみ。spec M-1/§11.1は統一(決めるのはD/PM)、変更前後を比較できるよう日付を記録。
- Search Ads: ブランド語・完全一致・日約50円を初回導線改善完了後(最大1ヶ月目第3〜4週)に、承認後実行。一般語追加=直近2週でCPI300円以下かつD1 20%以上。停止=CPI300円超で拡大しない、2ヶ月目LTVがCPIの約0.5倍未満で停止、1ヶ月目末D1 20%未満は体験優先。
- 戻る理由: 計測先行、実装は2ヶ月目以降。1ヶ月目の優先順位は①コンプラ整合②計測整備③初回導線改善(並行可、計測を遅らせない範囲)。着手前提=(a)1ヶ月目末にDL・DAU・D1が実測できている (b)あんでぃさんの承認。D1が取れない/20%未満なら体験改善を優先。
- IAP: 目標の分子に含めず別枠で記録。1ヶ月目は価格・導線・訴求を触らない。見直しは3ヶ月目判定時。削除購入者比率は週次記録(基準は購入が数件出てから)。目標にIAPを含めるかはあんでぃさんの判断が必要。
- 計測: まずASC+AdMobのみ、新規SDKなし。端末内カウンタは5点(最初の1局到達、完走、もう1局、遊び方を開いた回数、共有タップ)に限り端末外へ送信しない。申告不要の可能性が高い(推測)、実装と申告の突合が条件。
- ストア表現: 「オセロ」不使用(商標)。1局の時間は具体的な分数を書かず「サクッと遊べる」程度。「足して10」か「合計で挟む」のどちらかに絞り、説明文で補う。
- R1で記載(R2では問われていない): 月末中間チェックとしてDL月10件以上か。レビュー依頼は「あとで」。

### プロダクトマネージャー(PM)
- 結論: 3ヶ月は「到達」でなく「到達見込みの検証」。オーガニック中心のまま到達する見込みは低い(推測)。優先順位=測れる状態→戻る理由→判断。信頼度 低〜中。
- 必要DAU: 基準1人日7表示(DAU約160)、幅5〜10表示(DAU110〜220)、日3表示(約365)は下振れ感度。Mの20表示(DAU55)には賛成しない(現行はインタースティシャル2局目以降かつ3分以上+バナー850pt以上の端末のみ。推測)。1ヶ月目末の実測で置換。
- しきい値: 算式を固定し、数値は1ヶ月目末の実測で埋める(仮置きあり)。日次広告収益=DAU×1人日表示数×0.152円。Mの旧案DAU30=月2,500円は1人日約18表示を暗黙に置くため不使用。仮置き(推測): 継続=DAU100以上かつ日次70円以上かつD7 10%以上。保留=DAU40〜100またはD7 5〜10%(無料施策のみ1ヶ月)。撤退=DAU40未満かつ日次30円未満、またはD7 5%未満。30日平均+7日移動平均を併記。欠損日は除外せず代理指標で補う。代理指標=日表示÷基準7表示(推測)。母数が極小(月DL1桁)は比率より絶対数、保留で粘らず撤退側。
- 固定軸: 期間(3ヶ月、撤退ライン不動)。可変=範囲・予算(上限内、使い切らない)。下限=計測の正確さとコンプラ整合。保留は1回まで・無料施策のみ・判断の猶予であり撤退ラインの延長ではない。延長ならデッキ更新を合議で。品質固定(ルール理解・離脱の体験に限る)とは両立。
- 凍結: 1ヶ月目末の中間ゲートまで。3ヶ月凍結には賛成しない(収益側の仮説を検証できなくなる)。解除条件(全て)=1人日表示数が計測できている+広告表示後の離脱がD1から読める+あんでぃさんの承認。解除後は1回に1つだけ変える比較実験。Unity搭載ビルド配布も実験設計後に承認。「広告を結果ダイアログの裏に隠さない」は不変条件。M-1「3局に1回」は古い記述の疑い濃厚(実装は2局目以降かつ3分以上でspec§11.1と一致、一次確認範囲)。文書訂正のみで挙動は変えない。
- Search Ads: 初回導線改善後(目安1ヶ月目2週目、後ろ倒しは最大2週間、間に合わなければ3週目までに現行のまま開始)。完全一致・日約50円。一般語=ブランド語でCPI300円以下かつD1 20%以上を少なくとも2週間続けて。停止=CPI300円超で拡大しない、2ヶ月目LTVがCPIの約0.5倍未満で停止、1ヶ月目末D1 20%未満は拡大見送り。承認後のみ、提案のみ。
- 戻る理由: 計測完了が先、2ヶ月目に実装。1ヶ月目=1.指標定義と週次記録+コンプラ整合(提出なし) 2.初回導線(約5h) 3.原案者打診と無料告知。着手条件=計測が回っている+初回導線改善後にD1が取れる+1ヶ月目末ゲート通過。Dの順序(初回導線→結果共有→デイリー)に賛成。工数は戻る理由3点で約14h(共有4、デイリー・連続日数10)。承認後実装。
- IAP: 目標は「広告収入のみ」を維持、IAPは別行で参考値。見直しは3ヶ月目の判断時。週次で購入者数÷累計DLを記録。仮置き(推測): 購入者比率5%超かつ広告収益が伸びない場合に価格・訴求の見直し候補。母数が小さい間は件数。自社バナー文言変更は広告の変更にあたり承認事項。
- 計測: 1ヶ月目はASC+AdMobのみ。端末内カウンタは2ヶ月目の判断材料。端末内で見るだけでは自分以外のユーザー分を読めず、集計経路がなければDAUの代理にならない(エンジニア確認)。申告・審査への影響は低リスクだが未確認。
- ストア表現: 「オセロ」不使用、時間の具体分数は書かない、「10で返す」等はspecと照合してから。

### プロダクトデザイン責任者(D)
- 結論: 足りないのは広告枠でなく「最初の1局の理解」と「もう1局の理由」。実測は30日で3DL・表示164回で効果を測れない。体験改善は小さい順に ①初回導線の摩擦除去 ②結果カードの共有化 ③デイリーお題。信頼度 中〜低(コードと文書の読解のみ、実機・スクショ未確認)。
- 必要DAU: N表示を採用値にしない。デッキは「55〜365の幅、実測前は確定しない」。PMの5〜10表示の併記なら合意。表示数の前提を置くために枠追加・頻度緩和を使わない。
- しきい値: 数値はPMに委ねる。DAU100案がeCPM152円と整合。DAUが数人規模のうちは連続2週間以上の週次中央値を併記(推測)。月3DLのうちは比率だけで撤退判断は危ういため件数を併記。月DL1桁のまま2ヶ月目末なら3ヶ月目を待たず投資停止を検討してよい。
- 固定軸: 品質と撤退ライン(3ヶ月)。予算は上限、使い切らない。可変=範囲・施策順。下限=広告を結果ダイアログの裏に隠さない、タップ領域とアクセシビリティ、「原案: @bdgame_」表記。保留1ヶ月は許容(無料施策のみ・新機能なし)。
- 凍結: 3ヶ月目末の判断まで(DAUが数人規模では効果が測れず体験悪化のコストだけ残る、推測)。解除=①DAUまたは代理指標が継続しきい値を超え ②「最初の1局完走率」「2局目開始率」が悪化していない場合のみ、変更案を合議へ(実行は承認後)。M-1/§11.1は実装を確認しspecを統一、文書の訂正として扱い凍結の例外にしない。
- Search Ads: 初回導線改善後に開始を推す。1ヶ月目後半(導線改善反映後)の折衷案なら合意。一般語追加の条件に賛成。ただしD1が取れない間は追加しない、「最初の1局完走率」が極端に低い場合も追加しない。停止条件に異論なし。承認後。
- 戻る理由: 2ヶ月目で合意。ゲート=計測が動いている(最低ASC+AdMob週次)+1ヶ月目末にD1または代理指標がある+あんでぃさんの承認。結果共有カードは小さい変更(約4h、推測)なので1ヶ月目終盤に先行してよい(承認後)。DAUが見えるまで待つと2ヶ月目の判断材料が間に合わないリスク。
- IAP: 広告収入に限定、IAPは別枠で併記。見直しはDAUが見える2ヶ月目以降、1ヶ月目は変えない。売り込みを強めず、自社バナーが宣伝に見えないか実機確認が先。購入者比率は単純に悪化とだけ読まない(推測)。
- 計測: 端末内イベントカウンタ(5点、送信しない)+ASC/AdMobを優先。申告への影響は推測で確認が必要。
- ストア表現: 「オセロ」不使用、分数は書かない。見出しは「合計で挟んで返す」程度、SS1枚目は裏返る瞬間、末尾に「原案: @bdgame_」。反映は承認後。
- R1で記載(R2では問われていない): リワード広告はspecで非導入決定済みのためやらない。工数(推測)=初回導線約5h、共有約4h、デイリー・連続日数約10h、ストア表現約4h=約23h(約50時間の内数)。費用は原則0円(有料素材は事前承認)。

## 4. 残った対立点
