# 合議記録: KPI定義と週次記録（2026-10-25）

論点: 週次で固定する指標、欠損・代理の表記、記録の置き場所と取得方法。判断の土台はデッキ第6・10項。進行はスクラムマスター（意見なし）。第1ラウンドのみ実施（専門家は役割定義・docs/facts.md・デッキだけを受領）。事実の追加: ASC APIでトオカエシの analytics report request が0件（読み取りのみ確認、作成はしていない）。

## 各役割の意見（要旨）
- **マーケ**: 実測5＋代理2に絞る。製品ページ表示・インプレッションを足す。流入元はASCのDL元区分を第一に、無料は識別付きリンク、有料は別列（未出稿）。欠損は「未取得（理由・予定日）」と「取得不能」を区別。App Analyticsの作成承認を最優先で求める（遅れると過去データが取れない可能性＝推測）。
- **PM**: 8項目（DL・日表示・eCPM・日次広告収益・DAU・D1/D7・1人日表示数・IAP件数）に固定。流入元は別議題。判定は第10項に直結。AdMobは週1手入力が最大の運用リスク。2週途切れたら保留の合図。Markdown表1枚。
- **デザイン**: 実測と代理を分ける。体験指標は「未計測」の枠を固定し推定値で埋めない。各行に母数。末尾に定性観察3行。しきい値は決めない。
