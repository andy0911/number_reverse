# 原案者への打診文と無料告知の下書き（送信・投稿はしない）

作成: 2026-10-25。方針は[合議の決定記録](consensus/2026-10-25-outreach-and-announcement.md)（3専門家が独立に意見を出し、対立点なし）。
**投稿はあんでぃさんの確認後に、あんでぃさん自身が行う。**

## 更新（2026-10-25、あんでぃさんの決定）
- 原案者からは許可取得済みのため、**A（打診文）は不要**。以下のA節は経緯として残す（送らない）。
- 告知は**最初から「原案: @bdgame_」を出す**。原案者に触れない版ではなく、クレジット付きの版を使う。
- SNS発信は**1ヶ月目から**（費用0、週1〜2本、3〜4週）。
- 元の方針（打診が先・返答前は言及しない）は、許可取得済みの前提で不要になった。

## 守る表現ルール（3者一致）
- 返す条件は「自軍の合計＞相手軍の合計」（spec §5.1）。「10で返す」「足して10で挟む」は書かない。10は「表と裏の和」（補助）。
- 「オセロ」語、分数、「3分で1局」、「新感覚」「話題」「人気」などの根拠のない形容は書かない。
- 許諾済み・公認・コラボと読める表現、依頼しない事項（拡散・引用・報酬）は書かない。収益目標も書かない。
- 実機の公開済み画面だけを使う（未リリースの結果共有カード・Unity広告の画面は使わない）。

## A. 【不要・送らない】原案者 @bdgame_ への打診文（X の DM）
送る順序: 告知より先。DM が閉じていた場合は、公開リプライで連絡先だけ聞く（B 案）。返答がなくても催促は1回までとし、約2週間後に「原案者に触れない版」で告知を進める。

### A-1. DM 本文
```
はじめまして。あんでぃと申します。
bdgame_さんの数字リバーシの原案をもとに、iOSアプリ「トオカエシ」を個人で作り、公開しました。
https://apps.apple.com/jp/app/id6817160128

アプリの説明文とアプリ内には「原案: @bdgame_」と記載しています。
お忙しいところ恐れ入りますが、次の3点だけ、はい・いいえ程度で構いませんので教えていただけますか。

1. 原案をもとにアプリを公開していることについて、問題はありませんか（許諾の状況の確認です）。
2. クレジットの表記（文言・位置）に、ご希望はありますか。
3. 私のX投稿で、bdgame_さんのお名前を出してご紹介してもよいでしょうか。

ご返信は急ぎません。内容に問題があれば、ご指摘のとおりに直します。
拡散やご紹介のお願いではありませんので、ご負担にならない範囲で結構です。
```

### A-2. DM が使えない場合の公開リプライ（B 案）
```
bdgame_さん、突然失礼します。数字リバーシの原案をもとにiOSアプリを個人で公開しました（説明文に「原案: @bdgame_」と記載）。表記などで確認したい点があり、DMかご連絡先を教えていただけると助かります。
```

## B. 無料告知（X）。週1〜2本、3〜4週
識別付きリンク: App Store のキャンペーンリンクで `ct`（キャンペーン名）を投稿ごとに変える（例 `?ct=x_flip`）。`pt`（プロバイダID）の要否は App Store Connect で要確認【未確認】。測定は ASC の流入元、件数で見る（DL は30日で3件【実測】）。

### 投稿案（原案者のクレジットは各投稿に添える。例は下の「クレジット付き」参照）
**投稿1「裏返る瞬間」**（画面録画6〜10秒、盤面と合計が見える場面）
```
数字の合計で相手の駒を挟んで、裏返すリバーシ。
自分の軍の合計が相手より大きいと、挟んだ駒が返ります。
iPhoneで遊べます → [URL ?ct=x_flip]
```

**投稿2「ルール1つ」**（静止画。合計の比較が分かる盤面。spec §5.1 の例のみ）
```
トオカエシのルールは、挟んだときの「合計」の勝負です。
自軍の合計が相手軍より大きければ、挟んだ駒を返せます。
表と裏の数字の和は10。裏返ると数字が変わるのがポイント（数字駒のみ）。
[URL ?ct=x_rule]
```

**投稿3「コーチモード」**（遊び方の画面録画）
```
ルールが難しそうなら、「遊び方を見る」から。
盤面を指し示しながら、合計で挟んで返す流れを説明します。
CPU戦も2人対戦もあります。 [URL ?ct=x_coach]
```

### クレジット付き（最初から使う）。各投稿の末尾に「原案: @bdgame_」を1行添えてもよい
```
トオカエシは、@bdgame_ さんの数字リバーシの原案をもとに作ったiOSアプリです（原案: @bdgame_）。
数字の合計で相手の軍を挟んで、裏返します。 [URL ?ct=x_credit]
```

## 出す前の確認（あんでぃさん）
1. X アカウントの準備（フォロワー数）。
2. 初回導線の確認（来訪者が遊び方にたどり着けるか。共有カードは2ヶ月目のため、来訪者の保持は期待しない）。
3. 投稿用の実機画面録画・画像の素材（盤面は spec §5.1 に沿った数字駒の例）。
5. 投稿の停止条件（案）: 4週間で投稿由来のDLがゼロなら、頻度を下げて手段を再検討する。
