## あんでぃさんの作業（これが終わるまで投稿されない）
1. X開発者コンソール（https://console.x.com ）で、投稿するXアカウントにひも付くアプリを作成し、権限を Read and Write にする。
2. API Key / API Secret / Access Token / Access Token Secret を発行する（Access Token は Read and Write 権限で再生成）。
3. 開発者コンソールでクレジットを少額（例 $5）購入する。
4. クラウド環境の環境変数に `X_API_KEY` `X_API_SECRET` `X_ACCESS_TOKEN` `X_ACCESS_SECRET` を設定する。
5. クラウド環境のネットワーク許可に `api.x.com` を追加する。

## 運用
- キュー: `docs/x-queue.json`。`approved: false` の間は `--send` でも投稿しない。
- 投稿前チェック（自動）: 「原案: @bdgame_」、`?ct=`、禁止語（オセロ・「10で返す」等）、文字数。NGなら全体を止める。
- 実行: `python3 scripts/x_post.py`（検査のみ）／`--send`（予定時刻を過ぎた未投稿を投稿）。クラウドの定期実行から `--send` を呼び、書き戻したキューをコミットする想定（定期実行の登録は、初投稿日の確定後）。
- 初投稿日が決まったら、`scheduled_at` を実日付に更新し、Apple Ads の開始日（初投稿の8日目）を同時に決める。
