# App Store ページへのクレジット追記文面

アプリの原案者 @bdgame_（https://x.com/bdgame_）のクレジットを、App Store Connect の説明文の末尾に追記する。
審査提出・メタデータ反映は外部公開操作のため、ユーザーの指示があるまで行わない。

## 追記する文面（説明 / Description の末尾）

```
原案: @bdgame_ (https://x.com/bdgame_)
```

## 反映手順

1. App Store Connect > アプリ > 配信用バージョン > 日本語の説明 の末尾に上記を1行追加する（空行を1行あけてもよい）。
2. バージョン更新と同時に審査へ提出する（説明文はバージョンに紐づくため、提出は別途ユーザーの指示を待つ）。
