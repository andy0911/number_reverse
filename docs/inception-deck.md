# トオカエシ インセプションデッキ（初版・2026-10-25）

プロダクト目標: **トオカエシ単体の広告収入で、毎月5,000円を安定して稼ぐ。** 予算は月1万円まで（トオカエシ個別）。撤退ライン3ヶ月（撤退＝投資停止。アプリは消さない）。

作成方法: マーケティング専任者・プロダクトマネージャー・プロダクトデザイン責任者の独立サブエージェント3体が2ラウンドで意見を出し、スクラムマスター（意見なし）が整理した。各役割の意見・対立点・根拠は [合議の決定記録](consensus/2026-10-25-inception-deck.md)。
表記: 【実測】【算術】【推測】。付いていない数値は固定条件。【決定】は3者が合意した内容、【未決】はあんでぃさんの判断待ち、【承認待ち】は実行前にあんでぃさんの明示の承認が要る操作。デッキと矛盾する決定をするときは、デッキの更新も合議で決める。
